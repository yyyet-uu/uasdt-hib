What can we help with?
❓ Frequently asked
How do I earn points?
Watch available ads, complete verified tasks, maintain your daily streak and invite active users. Rewards are controlled by the server.
How does referral reward work?
Referral rewards should only be credited after the backend verifies the required activity. Do not trust client-side referral claims.
Which network is used?
USDT Hub uses BEP20 / BNB Smart Chain addresses. Double-check the address before any payout request.
What is the minimum withdrawal?
The current frontend configuration uses 10,000 PTS as the minimum withdrawal threshold.
Why are channels required?
Channel membership can be required to unlock the app according to the current account verification flow.
🔒 Security first
USDT Hub should only need your public BEP20 wallet address for payouts. Never send a private key, seed phrase, recovery phrase or wallet password to support.
